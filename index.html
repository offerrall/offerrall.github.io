Librerías de Python pequeñas, versionadas y publicadas en PyPI.

GitHub · PyPI

Tipos y formularios

  • pytypehint Compila type hints en contratos estrictos e inspeccionables. pip install pytypehint
  • pytypehintweb Capa de formularios web para pytypehint, sin framework. pip install pytypehintweb
  • pytypehintstore Filas de un dataclass validado, en memoria y respaldadas por JSON. pip install pytypehintstore
  • func-to-web Convierte funciones Python tipadas en interfaces web. pip install func-to-web
  • pytypeinput Type hints → metadatos de UI. pip install pytypeinput
  • pytypeinputweb Web Components para pytypeinput. pip install pytypeinputweb

CNC, láser y CAD

  • pycodecad Code-CAD con build123d: ventana que muestra y exporta lo que construye tu script. pip install pycodecad
  • pygrbl_build Genera G-code para láseres de diodo GRBL. pip install pygrbl_build
  • pygrbl_streamer Streamer de G-code para GRBL, thread-safe y tolerante a fallos. pip install pygrbl_streamer

Imagen, cámaras y despliegue

  • pyimagecuda Composición de imágenes acelerada por GPU. pip install pyimagecuda
  • pyezcams Captura webcams USB y las emite por RTSP/WebRTC con MediaMTX. pip install pyezcams
  • pyeasydeploy Despliegue de servidores Python simple y replicable. pip install pyeasydeploy
